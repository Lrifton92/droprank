## Filtré comme sybil
Multi-wallets industriels, bridges répétés de montants minuscules, mint NFT sans valeur pour transfert cross-chain, clusters même IP / même CEX de financement → **tout le cluster éliminé**. ~85% des nouveaux airdrops filtrent les sybils. Base = setup anti-sybil le plus sophistiqué des L2 (infra Coinbase : KYC, Verifications, Smart Wallet).
